# Portfolio Web & Admin Dashboard

Una landing page y portafolio personal moderno desarrollado desde cero con HTML5, CSS3 puro y JavaScript vanilla, integrado con **Supabase** como backend para la gestión de mensajes en tiempo real y autenticación.

## 🚀 Características

- **Diseño Moderno y Responsivo:** Interfaz atractiva utilizando gradientes, efectos *Glassmorphism* y animaciones fluidas con CSS.
- **Formulario de Contacto Functional:** Los mensajes de los visitantes se envían y almacenan directamente en la base de datos de Supabase.
- **Panel de Administración Privado (`/admin.html`):** Vista protegida donde el administrador puede visualizar todos los mensajes recibidos en una tabla estilizada.
- **Autenticación Segura:** Sistema de Login (`/login.html`) protegido por sesión de Supabase Auth para restringir el acceso al panel.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 (Flexbox, CSS Transitions), JavaScript (ES6+).
- **Backend & DB:** Supabase (Auth & Database).
- **Hosting:** GitHub Pages.
